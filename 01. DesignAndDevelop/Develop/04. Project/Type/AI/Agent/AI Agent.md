小Tips: 通常来说对应的 ai 使用其对应 Agent，使用效果会好一些。两个思路:

- 可以不进行多选一，而是电脑上同时使用多个 Agent 工具，切换 Agent 和模型来用。而不一定要追求在同一 Agent 上完成所有项目（除非多个项目之间的关联比较大）。
- 也可以不下载和使用那么多 Agent，关键是建立好默契，熟练使用。
