### AI Gateway

Vercel AI Gateway 是开始使用 AI SDK 的*最快方式*。访问来自 OpenAI、Anthropic、Google 和其他提供商的模型。使用 OIDC 进行身份验证 或 AI Gateway API 密钥

将您的 API 密钥添加到您的环境中：

.env.local

```
AI_GATEWAY_API_KEY=your_api_key_here
```

AI Gateway 是默认的全局提供商，因此您可以使用简单的字符串访问模型：

```js
import { generateText } from 'ai';

const { text } = await generateText({
  model: 'anthropic/claude-sonnet-4.5',
  prompt: 'What is love?',
});
```

您还可以显式导入并使用 gateway 提供程序：

```js
// Option 1: Import from 'ai' package (included by default)
import { gateway } from 'ai';
model: gateway('anthropic/claude-sonnet-4.5');

// Option 2: Install and import from '@ai-sdk/gateway' package
import { gateway } from '@ai-sdk/gateway';
model: gateway('anthropic/claude-sonnet-4.5');
```

### 使用专用提供商

您还可以直接使用 [first-party](https://ai-sdk.dev/providers/ai-sdk-providers)、[OpenAI-compatible](https://ai-sdk.dev/providers/openai-compatible-providers) 和 [社区](https://ai-sdk.dev/providers/community-providers) 提供商的软件包。安装该包并创建一个提供程序实例。例如，要使用 Anthropic：

```bash
# 四选一
pnpm add @ai-sdk/anthropic # pnpm
npm install @ai-sdk/anthropic # npm
yarn add @ai-sdk/anthropic # yarn
bun add @ai-sdk/anthropic # bun
```

```js
import { anthropic } from '@ai-sdk/anthropic';

model: anthropic('claude-sonnet-4-5');
```


您可以更改默认的全局提供程序，以便字符串模型引用在应用程序中的任何地方都使用您的首选提供程序。了解有关 [提供商管理](https://ai-sdk.dev/docs/ai-sdk-core/provider-management#global-provider-configuration) 的更多信息。

请参阅 [可用的提供商](https://ai-sdk.dev/providers/ai-sdk-providers) 以获取每个提供商的设置说明。

### 定制供应商

您可以构建自己的提供程序，将任何服务与 AI SDK 集成。 AI SDK 提供 [语言模型规范](https://github.com/vercel/ai/tree/main/packages/provider/src/language-model/v3) 确保提供商之间的兼容性。

```js
import { generateText } from 'ai';
import { yourProvider } from 'your-custom-provider';

const { text } = await generateText({
  model: yourProvider('your-model-id'),
  prompt: 'What is love?',
});
```

有关完整指南，请参阅 [编写自定义提供程序](https://ai-sdk.dev/providers/community-providers/custom-providers)。

## 浏览 Library

AI SDK 是用于构建 AI 应用程序的强大工具包。此页面将帮助您选择适合您需求的工具。

让我们首先快速概述一下 AI SDK，它由三个部分组成：

- [AI SDK Core](https://ai-sdk.dev/docs/ai-sdk-core/overview): 核心：一个与提供商无关的统一 API，用于通过法学硕士生成文本、结构化对象和工具调用。
- [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview): 一组与框架无关的挂钩，用于构建聊天和生成用户界面。
- [AI SDK RSC](https://ai-sdk.dev/docs/ai-sdk-rsc/overview):  使用 React 服务器组件 (RSC) 流式生成用户界面。目前开发处于实验阶段，我们建议使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview)。

### 选择适合您环境的工具

在决定使用 AI SDK 的哪一部分时，您首先考虑的应该是您正在使用的环境和现有堆栈。 SDK 的不同组件是针对特定框架和环境量身定制的。

| Library                                                     | Purpose                                                                                                                                                                           | Environment Compatibility                     |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| [AI SDK Core](https://ai-sdk.dev/docs/ai-sdk-core/overview) | 使用统一的API调用任何LLM<br>(e.g. [generateText](https://ai-sdk.dev/docs/reference/ai-sdk-core/generate-text) and [streamText](https://ai-sdk.dev/docs/reference/ai-sdk-core/stream-text)) | 任何 JS 环境（例如 Node.js、Deno、浏览器）                 |
| [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview)     | 构建流式聊天和生成式 UI<br>(e.g. [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat))                                                                                           | React 和 Next.js、Vue 和 Nuxt、Svelte 和 SvelteKit |
| [AI SDK RSC](https://ai-sdk.dev/docs/ai-sdk-rsc/overview)   | 将生成的 UI 从服务器流式传输到客户端<br>(e.g. [streamUI](https://ai-sdk.dev/docs/reference/ai-sdk-rsc/stream-ui))<br>目前开发处于实验阶段，我们建议使用 AI SDK UI。                                                 | 任何支持 React 服务器组件的框架（例如 Next.js）               |

### 何时使用 AI SDK UI

AI SDK UI 提供了一组与框架无关的挂钩，用于快速构建 **可用于生产的 AI 原生应用程序**。它提供：

- 完全支持流式聊天和客户端生成 UI
- 用于处理常见 AI 交互模式的实用程序（即聊天、完成、助理）
- 经过生产测试的可靠性和性能
- 跨流行框架的兼容性

### AI SDK UI框架兼容性

AI SDK UI 支持以下框架： [React](https://react.dev/), [Svelte](https://svelte.dev/) 和 [Vue.js](https://vuejs.org/) 。以下是这些框架支持的功能的比较：

| Function                                                                     | React | Svelte | Vue.js |
| ---------------------------------------------------------------------------- | ----- | ------ | ------ |
| [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat)              | ✅     | ✅      | ✅      |
| [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) tool calling | ✅     | ✅      | ❌      |
| [useCompletion](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-completion)  | ✅     | ✅      | ✅      |
| [useObject](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-object)          | ✅     | ❌      | ❌      |

### 何时使用 AI SDK RSC

> [!warning]
> AI SDK RSC 目前处于实验阶段。我们建议使用 AI SDK UI 进行生产。有关从 RSC 迁移到 UI 的指南，请参阅我们的迁移指南。

[反应服务器组件 (RSC)](https://nextjs.org/docs/app/building-your-application/rendering/server-components) 提供了一种构建 React 应用程序的新方法，允许组件在服务器上渲染、直接获取数据并将结果流式传输到客户端，从而减少包大小并提高性能。他们还引入了一种从应用程序中的任何位置调用服务器端函数的新方法，称为 [服务器操作](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations)。

AI SDK RSC 提供了许多实用程序，允许您将值和 UI 直接从服务器传输到客户端。但是，重要的是要了解当前的限制：

- 取消：目前，无法使用服务器操作中止流。这将在 React 和 Next.js 的未来版本中得到改进。
- 增加数据传输：使用 `createStreamableUI` 可能会导致二次数据传输（与生成文本的长度成二次方）。您可以使用 `createStreamableValue` 来避免这种情况，并在客户端呈现组件。
- 流媒体期间重新挂载问题：使用 `createStreamableUI` 时，组件在 `.done()` 上重新挂载，导致 [闪烁](https://github.com/vercel/ai/issues/2232)。

鉴于这些限制，我们建议将 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 用于生产应用程序。

## Next.js App Router

AI SDK 是一个功能强大的 TypeScript 库，旨在帮助开发人员构建人工智能驱动的应用程序。

在本快速入门教程中，*您将构建一个具有流式聊天用户界面的简单代理*。在此过程中，您将学习在自己的项目中使用 AI SDK 所必需的关键概念和技术。

如果您不熟悉 Prompt Engineering 和 HTTP Streaming 的概念，您可以选择先阅读这些文档。

### 先决条件

要遵循此快速入门，您需要：

- Node.js 18+ 和 pnpm 安装在本地开发计算机上。
- Vercel AI 网关 API 密钥。

如果您尚未获得 Vercel AI Gateway API 密钥，可以通过注册来获得 在维塞尔网站上。

### 创建您的应用程序

首先创建一个新的 Next.js 应用程序。此命令将创建一个名为 my-ai-app 的新目录，并在其中设置一个基本的 Next.js 应用程序。

> 当提示使用 App Router 和 Tailwind CSS 时，请务必选择“是”。如果您正在寻找 Next.js Pages Router 快速入门指南，可以在这里找到。

```bash
$ pnpm create next-app@latest my-ai-app
Would you like to use the recommended Next.js defaults? »
- Yes, use recommended defaults (App ts eslint ...)
- No, custom
```

导航到新创建的目录：

```bash
cd my-ai-app
```

#### 安装依赖项

在项目根目录中创建 .env.local 文件并添加 AI Gateway API 密钥。此密钥通过 Vercel AI Gateway 对您的应用程序进行身份验证。

> 本指南使用 Vercel AI Gateway 提供商，因此您可以使用一个 API 密钥访问来自不同提供商的数百个模型，但您可以通过安装其软件包来切换到任何提供商或模型。查看可用的 AI SDK 提供商以获取更多信息。

```bash
# 四选一
pnpm add ai @ai-sdk/react zod
npm install ai @ai-sdk/react zod
yarn add ai @ai-sdk/react zod
bun add ai @ai-sdk/react zod
```

#### 配置您的 AI Gateway API 密钥

在项目根目录中创建 .env.local 文件并添加 AI Gateway API 密钥。此密钥通过 Vercel AI Gateway 对您的应用程序进行身份验证。

```bash
touch .env.local
```

编辑 .env.local 文件：

```bash
AI_GATEWAY_API_KEY=xxxxxxxxx # 将 xxxxxxxxx 替换为您的实际 Vercel AI Gateway API 密钥
```

> AI SDK 的 Vercel AI Gateway Provider 将默认使用 AI_GATEWAY_API_KEY 环境变量。
