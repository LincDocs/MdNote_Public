### 发布准备 (准备过就不需要再准备)

自动发布版

有点麻烦，主要是我尝试时感觉网站老有bug。
像 [Azure DevOps](https://app.vsaex.visualstudio.com) 的 `Continue` 按钮按了没反应，无法注册。改域名发现注册好了。后来创建组织时也是。
根据 [创建发布者](https://liiked.github.io/VS-Code-Extension-Doc-ZH/working-with-extensions/publish-extension#%E5%88%9B%E5%BB%BA%E5%8F%91%E5%B8%83%E8%80%85) 的说法，转到 [Visual Studio Marketplace 发布者管理页面](https://marketplace.visualstudio.com/manage)。然后去创建组织。
好像绑定账号还要填具体街道级地址和卡号，麻烦。

手动发布，较简单

- https://marketplace.visualstudio.com/, 然后登录后依次按:
  - Publish extensions
  - New extension > VSCode
  - 选中本地的 `.vsix` 文件并 Upload

### package.json

其他软件的插件开发体系，一般有个专门的清单文件 manifest.json，而 vscode 直接将 package.json 当作清单文件来用

```json
{
  "name": "smart-region", // VS Code 使用 `<publisher>.<name>` 作为一个插件的ID
  "displayName": "SmartRegion",
  "description": "Smartly create regions",
  "version": "0.0.1",
  "engines": {
    "vscode": "^1.84.0" // 依赖的最低 VS Code API 版本
  },
  "categories": [
    "Other"
  ],
  "activationEvents": [], // 激活事件
  "main": "./out/extension.js", // 插件的主入口
  "contributes": { // 配置点
    "commands": [ // 配置命令名与命令id的对应关系
      {
        "command": "smart-region.helloWorld",
        "title": "Hello World"
      }
    ]
  },
  "scripts": {
    "vscode:prepublish": "npm run compile",
    "compile": "tsc -p ./",
    "watch": "tsc -watch -p ./",
    "pretest": "npm run compile && npm run lint",
    "lint": "eslint src",
    "test": "vscode-test"
  },
  "devDependencies": {
    "@types/vscode": "^1.140.0",
```

### 插件入口文件

src/extension.ts

```ts
// 'vscode' 模块包含 VS Code 扩展性 API
// 在下方导入该模块，并在代码中使用别名 vscode 引用它
import * as vscode from 'vscode';

// 当你的扩展被激活时会调用此方法
// 你的扩展会在命令第一次执行时被激活
export function activate(context: vscode.ExtensionContext) {

	// 使用控制台输出诊断信息（console.log）和错误信息（console.error）
	// 这行代码只会在你的扩展被激活时执行一次
	console.log('Congratulations, your extension "smart-region" is now active!');

	// 该命令已在 package.json 文件中定义
	// 现在通过 registerCommand 提供该命令的实现
	// commandId 参数必须与 package.json 中的 command 字段匹配
	const disposable = vscode.commands.registerCommand('smart-region.helloWorld', () => {
    // 你放在这里的代码会在每次执行该命令时运行
		// 向用户显示消息框
		vscode.window.showInformationMessage('Hello World from SmartRegion!');
	});

	context.subscriptions.push(disposable);
}

// 当你的扩展被停用时会调用此方法
export function deactivate() {}
```
