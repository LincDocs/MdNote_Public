# 小键盘你真的知道怎么用吗？

转自: [小键盘你真的知道怎么用吗？](https://www.bilibili.com/video/BV1oUvXBAEik/)

## 启用鼠标键

`Alt+Shift+NumLock`

- 方向键: `12346789` 控制方向
- 点击: 单击 `5`
  - 拖动/按住模式: 单击 `0` (不能按住 `5`，按下后也无需再单击 `5`)
  - 左键模式: `/` (默认)
  - 右键模式: `-`
  - 左右同时按下: `*`
  - 双击模式: `/` + `+` (不能连续按两下 `5`)

## 使用 Alt Code

Alt + 小键盘

```
 161 ¡
 191 ¿
 198 Æ
 230 æ
0156 œ
 215 ×
 247 ÷
2248 (约等于)
2260 (不等于)
```

> [!WARNING]
> 注意: 如果超出255，则需要修改注册表才能支持

### 查询 Alt Code

有多种方法:

- Microsoft Windows 帮助页
- Word 的插件符号 > 其他符号
- 问 AI 大模型
- 查看 Windows 的字符映射表，`win+r` 然后输入 `charmap` 并确定即可打开
  打开后需要在下面下拉框中的分组依据选择 `Unicode 子范围`

一般查出来的是16进制的，我们需要转成10进制后才能通过 Alt Code 使用。有多种方法:

- 使用 windows 自带计算器，切换到程序员计算器
- 使用在线工具

### 突破255限制

需要修改注册表

1. 打开注册表。可以是 `Win+R` > 输入 `Regedit` > Enter
2. 进入路径 `计算机\HKEY_CURRENT_USER\Control Panel\Input Method`
3. 右键 > 新建 > 字符串值 > 名称为 `EnableHexNumpad` 且数值为 `1`

或者使用cmd指令，在cmd中运行:

```bash
reg add "HKEY_CURRENT_USER\Control Panel\Input Method" /v EnableHexNumpad /t REG_SZ /d 1 /f
```

若需恢复则删除该注册表项即可
