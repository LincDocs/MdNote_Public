文件分类系统（树系统）

文件分类系统（树系统）

目录

V0

[略]，旧笔记本D盘所用的分类系统

V1

新特性

  • V0不存在单目录下的文件数限制，只有第二第三分支混合、用前缀进行区分

    而V1有了单目录文件数限制，并放弃了前缀使用

  • 将笔记系统、文件系统，两者的树形归类合并通用

主分支

（笔记系统）

  • Private_XXX
    私有，不可暴露于互联网中，但可以暴露于局域网中。默认权限是仅自己可访问
    • 基本同Public
  • Public
    完全公有，可暴露于互联网中
    • Doc
      文档类，或者以文本形式存储的其他东西，通常大小比较小
      • Paper
        论文类
      • Pdf
        Pdf资料
      • Story (NULL)
        小说/故事类
      • 网页收藏夹
        网页链接或html备份
    • HS
      黄色
      • Gif
      • Interaction
      • Pic
      • Temp
      • Video
      • Voice (NULL)
    • Project**（仅限Private）**
      工程
      • <生产力分支>
    • Res
      资源
      • <生产力分支>
    • Res2
      资源
      • <增强类分支>
    • Soft
      软件
      • <生产力分支>
    • Soft2
      软件
      • <增强类分支>
    • Soft3
      其他软件、偏娱乐社交类
    • Teach
      生产力教程
      • <生产力分支>
    • Teach3
      其他教程
    • Tool
      工具/插件，必须依赖于软件使用，否则即便与软件有依赖关系也不属于Tool，而顶多是个ToolSoft
      • <生产力分支>
    • Tool2
      工具/插件，必须依赖于软件使用，否则即便与软件有依赖关系也不属于Tool，而顶多是个ToolSoft
      • <增强类分支>

生产类分支

计算机生产力

  • 3D
    • 各种软件，主要是三维软件很多都是啥活都能干，所以也不用怎么分类了
  • Dev（相当于笔记分类中的Project类）
    • Project
      项目。体系繁多，难分类
      • All
        编译器/环境等
      • Android
        安卓应用
      • Application
        应用，一般是跨平台应用
      • Artificial_Intelligence
      • Game
      • Hack
      • Site
      • Tools
      • Web
  • Doc
  • Mix
  • Plane
  • Vedio
  • Virtual
  • Voice
