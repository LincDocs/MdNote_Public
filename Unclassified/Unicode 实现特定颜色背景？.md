# Unicode 实现特定颜色背景？

前面群友们说起特定颜色背景的标准范式，我就在想，通过 unicode 方式实现有没有可能

## 突发奇想

我突然想到一点：
- unicode 字符有那种特殊字符（显示位置>占用位置，可以用来堆叠大量字符在小量空间，如声调字母），
- unicode emoji 也有那种肤色字符（肤色字符+人物 emoji = 带肤色的人物 emoji 👩🏻👩🏿，当然这个的原理和上一个不同，这个是 OpenType 特性，将字符序列替换成变形字体。好像要占用大量的字体空间）。

那是否有 Unicode 字符，能够直接使用字符来模拟下滑线、删除线、类 `🟥` 实现的多色高亮背景？（组合使用，而非专门设计类 🅰️🅱️ 的字符）

例如我自定义两个 Unicode 字符，其占用宽度为0，显示宽度为一个汉字/一个英文 (需等宽字体)，输入该字符再输出汉字/英文，就能实现带背景的文字？（有些类似 `/𝙋𝙍𝙏⃟𝙎/ /𝙋𝙍⃟𝙏𝙎/`）
