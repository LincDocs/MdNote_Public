  - Folder Navigator | 搜索文件夹
  - Folder Notes  | 文件夹自动关联说明笔记
  - Hide Folders  | 隐藏对应正则规则的文件夹
  - MySnippets    | css片段管理
  - Rencent Note  | 最近打开过的笔记
- 渲染类           | 美化原md显示，可选使用新语法

  - Chat View QQ  | QQ/Wechat聊天视图
  - Dynamic Highlights | 支持正则匹配文本高亮
  - Mehrmaid      | mermaid with markdown
  - meta bind     | buttons next，自定义功能按钮

  - TikZJax       | 画公式图
- 独立功能         | 可以作为独立软件使用 / 从其他独立软件中迁移过来的
  - Ace Code Editor | VSCode 编辑器
  - Calendar      | 日历
  - Dataview      | 用脚本查询和展示笔记元数据，生成动态视图
  - Excalidraw    | 白板软件的功能
  - Kanban        | 看板软件的功能
  - NodeFlow      | 节点流软件管理
  - Slides Extended | 幻灯片
  - Thino         | 记录想法和短信息到笔记中
- IO类 | 导入导出、外部协同
  - Advanced URI  | 通过URI来管理
  - APIRequest
  - Local REST API
- 其他
  - I18N          | 插件翻译
